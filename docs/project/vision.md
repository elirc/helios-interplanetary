# Product direction

Helios operates fictional commercial infrastructure across Earth, orbit, the Moon, and eventually Mars. Atlas covers business workflows; Odyssey covers physical operations. Their value is visible cross-domain behavior, such as a failed pump requiring inventory, procurement, cargo, technician assignment, and repair.

Build a system the human developer can direct, inspect, explain, and evaluate with coding agents. Prefer verified scenarios, defensible transaction boundaries, useful observability, and compelling demonstrations. Do not optimize entity counts, framework counts, agent counts, or time spent running agents.

Start with a modular TypeScript monolith and PostgreSQL. Extract services or add infrastructure only when a concrete requirement or selected learning experiment justifies it. Product agents arrive after deterministic domain workflows and server-authorized tools.

The original domain catalog remains available in the source specification. `HELIOS-AGENTIC-ENGINEERING-PROMPT.md` is the revised execution direction. Teaching material lives separately in `upskilling/`, following the user's explicit request.
